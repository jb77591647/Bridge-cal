# Bridge-cal · 桥梁下部结构三维参数化建模与工程量计算

面向**U 形桥台**与**桥墩**的方案阶段工具：改参数 → 三维模型实时重建 → 工程量表同步刷新。

两个页面都是**单文件 HTML**（three.js 已内嵌；桥台页另内嵌 MathJax 与 OMML 转换样式表，约 3.0 MB，桥墩页约 0.66 MB），不依赖网络、后端或任何构建环境，双击即可打开，也可以直接发给同事或业主查看。

| 文件 | 内容 |
|---|---|
| `U型桥台三维参数化模型.html` | U 形桥台：L 形台帽（帽梁 + 背墙）、前墙、两道侧墙、1～2 层基础、台腔回填、开挖土石方 |
| `桥墩三维参数化模型.html` | 桥墩：盖梁（墩帽，变截面+两端挡块）、实体矩形墩 / 圆柱式墩（n 根单排）、1～2 层扩大基础、开挖土石方、稳定与承载力验算 + 导出.docx验算书 |

## 快速开始

1. 双击任一 html 文件（建议 Chrome / Edge）。
2. 左栏改参数，右侧三维模型与下方工程量表实时更新。
3. 鼠标左键旋转、右键平移、滚轮缩放；工具栏有 5 个视角预设（纵桥向 / 横桥向 1、2 / 俯视平面 / 45°视角）。
4. 需要交付时点「导出 CSV」或「打印」（打印自动隐藏左栏与工具栏，只出图与表）；要出验算书就点「稳定与承载力验算」卡片标题**最右侧**的「导出.docx验算书」（默认即蓝底白字的醒目按钮，悬停时提亮；下载文件名 `项目名-验算书.docx`，公式是 Word 原生对象，双击可编辑）。

### 交互细节

- **参数聚焦高亮**：点进任一输入框，三维视图里**该参数实际量取的那条边/那段量线**以橙色粗管（可穿透显示）约 2 Hz 脉冲闪烁；失焦即消失。用于「这个参数到底管哪儿」，不必再逐个读参数名。
  - 尺寸类参数只画它自己的量线（如墩身高 H 画四条竖直棱、基础高画四角竖棱、开挖各高度画单条竖线）
  - 下拉框（材料）聚焦时高亮对应构件整体
- **信息卡折叠**：点卡片标题栏折叠/展开，折叠不影响任何计算。参数多时把不常改的卡折起来，左侧一屏放得下。
- **左栏独立滚动**：左栏贴顶固定，输入靠下参数（如开挖土石方）时模型始终在视野内。

| 牛腿悬出宽度 b腿 | 0.30 | 自背墙背面向台后悬出的水平长度 |
| 牛腿槽口高度 h槽 | 0.30 | ≈搭板厚度；自背墙顶向下量至牛腿顶面（槽口底面／搭板搁置面） |
| 牛腿高度 h腿 | 0.30 | 外端竖面高度（自顶面向下量至端部底面） |
| 牛腿加腋高度 h腋 | 0.30 | 根部**截面变化（斜升）段**的竖向高度，即根部总高比端部高出的一段 |
| 牛腿顶面标高 | 自动 | = 背墙顶 − h槽（相对**基础底面** 0.000；前墙底标高 = 基础总厚） |

牛腿以帽梁中心左右对称布置（横桥向长度 = L腿，默认 7 m），贴背墙背面沿台后悬出 b腿。**竖向以背墙顶为基准**：顶面（槽口底面）＝背墙顶 − h槽；断面为直角梯形——外端竖面高 = 牛腿高度 h腿，根部下缘再按加腋高度 h腋 斜升，根部总高 = h腿 + h腋。因此：端部底面 = 顶面 − h腿，根部底面 = 顶面 −(h腿 + h腋)。牛腿加高或加腋加大时根部向下延伸，底面可低于帽梁顶面（此时贴帽梁背面，位于帽梁平面轮廓之外，体积不与帽梁重复）。体积 `V = L腿 × b腿 × (h腿 + h腋/2)`。

**竖向限值**：h槽 + h腿 + h腋 ≤ 帽梁高 + 背墙高（牛腿全部落在台帽高度范围内，根部底面最深到帽梁底）。超出时按下列规则自动修正，并把修正值写回参数输入框：

1. 先修正加腋高度：h腋 ← 帽梁高 + 背墙高 − h槽 − h腿；
2. 若修正后 h腋 ≤ 0（即 h槽 + h腿 本身已超限），则取 h腋 = 0，并把牛腿高度修正为 h腿 ← 帽梁高 + 背墙高 − h槽。

三维视图的构件开关中牛腿有独立开关（`牛腿`），可单独显隐，不再跟随「帽梁」；牛腿与帽梁同色。

## 计算方法

### 体积

- **矩形构件**（帽梁、背墙、基础各层、实体矩形墩身）：长 × 宽 × 高。
- **牛腿**（直角梯形断面，横桥向长 L腿）：L腿 × b腿 × (h腿 + h腋/2)。
- **圆柱墩身**：n × πd²/4 × H。
- **放坡类构件**（侧墙两道、台腔回填、土方、石方）统一采用**分段拟棱台公式**：

```
V = Σ hᵢ/6 · (A下 + 4·A中 + A上)
```

分段的依据：
- 侧墙、回填：上/下段分界（z = h2）与前墙顶折点（前端缘背坡转竖直处）
- 开挖：每级分级平台位置 + 石土分界面

在这些分段内部，断面面积随高度是**二次函数**，该公式对每段**解析精确**。

与之对比，经典棱台公式 `V = h/3·(S₁ + S₂ + √(S₁S₂))` 只在**顶底面相似**时精确。本模型的坑底（如 15 × 9）与坑口不相似、侧墙顶底断面也不相似，套用经典公式会产生**系统性偏小（约 0.01%～0.07%，随放坡段高度增大而增大）**，因此计算表不使用经典公式。

> 表中还给出三维网格的独立体积测量（散度定理，逐面按形心归一化朝向后求和），与拟棱台公式结果相互印证。

### 开挖与分级放坡

- 坑底 = 最底层基础外轮廓 + 每侧工作宽度 c；坑底标高 = 基础底面
- 现状地面标高 = 坑底标高 + H挖
- 自坑底向上分层：下层石方（h石）、上层土方（h土），层间连续，坡比按 m石 / m土 放坡；h土 > H挖 时按 H挖 截断
- 分级放坡：自坑底每累计 h分（默认 5 m）设一道分级平台，平台处开挖线每侧水平外移 b平（默认 1 m）后继续放坡，重复至地面。故 H挖 = 12 m 时共 2 道平台（@5、@10）

### 台腔回填

前缘为前墙背坡面 / 帽梁后缘 / 背墙后缘，顶面填至侧墙顶，背墙顶以上按竖直面近似；同样用拟棱台分段求和，不计入圬工合计。

**制动力自动计算**（JTG D60—2015 第 4.3.6 条）

- 一个设计车道的车道荷载：均布 qk = 10.5 kN/m，集中荷载 Pk 随加载长度内插（L ≤ 5 m 取 270 kN，L ≥ 50 m 取 360 kN，中间 Pk = 270 + 2(L−5)）
- 一个设计车道制动力 T₁ = max(10% × (qk·L + Pk), 下限)，下限公路—Ⅰ级 165 kN、Ⅱ级 90 kN
- 同向多车道：2 车道 ×2.00、3 车道 ×2.34、4 车道 ×2.68
- 常规跨径下 10% 往往小于下限（L = 20 m 时仅 51 kN），实际由 165 kN 控制；L 超过约 123 m 才转为 10% 控制

**台后主动土压力**（库仑通式，整段按**一面挡墙**计算，填土面水平 β = 0）

整段挡土高度统一按前墙背坡的斜墙计（α = 90°+θ，θ = atan(1/m1)），三角形分布，只用一个 Ka、一个合力 Ea，不再区分上下段。结果表在第 2 节「**制动力 Hk**」行下方逐行列出 **Ka、Ea 的计算公式**（先给符号式、再给按当前参数代入的数值式，末列即计算值）；EaV 在 ΣM稳 段另行给出 `EaV = Ea·sin(θ+δ)` 与力臂算式（基础前伸 + t1 + (H1−yc)/m1，合力点高于前墙顶时取竖直面 t1）。

- `Ka = sin²(α+φ) / [sin²α · sin(α−δ) · (1 + √(sin(φ+δ)·sinφ / (sin(α−δ)·sinα)))²]`；m1 = 0 且 δ = 0 时退化为朗肯 `Ka = tan²(45° − φ/2)`
- 三角形分布 `Ea = ½·Ka·γs·h填²·B`，合力点在距挡墙底 h填/3 处
- 合力与水平方向成 **θ+δ**：`EaH = Ea·cos(θ+δ)`、`EaV = Ea·sin(θ+δ)`；作用点 x = 墙背面在 yc = h填/3 高度处 `t1 + (H1 − yc)/m1`（yc 已在前墙顶以上时取竖直面 `t1`）
- **EaV 计入 ΣV 与 ΣM稳**（δ>0 时向下，对滑移与倾覆均有利）
- 退化与等价性：h填 ≤ 前墙高（H1）时本就是精确的单段斜墙；m1 = 0（竖直墙）时与库仑/朗肯单段公式严格相等
- 默认值（φ=30°、δ=20°、m1=3、h填=6.5、B=12）：Ka = 0.183，**EaH = 653.8 kN、EaV = 518.8 kN**
- **与「上下分段」口径的误差**：帽梁/背墙段（h填 > H1 的部分）实际挡土面竖直、Ka 略大，单段口径把这段也按斜墙计，**EaH 小约 4.8%（偏不安全侧）**。默认工况下由此产生的验算结果偏差：**Kc 偏大 +4.1%、K0 偏大 +6.8%、e 偏小 −2.7%、p均 ±0.0%、p最大 偏小 −0.8%、p最小 偏大 +1.9%**。m1 = 0 或 h填 ≤ H1 时两种口径严格相等（误差 0）；m1 越小、填土越高误差越大——m1=2、h填=6.5 时 EaH 差 −9.3%、K0 差 +11.6%；m1=1.5 时 EaH 差 −16.1%、K0 差 +17.4%；h填=8 时 EaH 差 −11.8%、K0 差 +19.5%。需要更精确的复核时按上下分段手算补差。

**计算内容**

1. **竖向力** ΣV = 支座反力 Nk + 圬工自重（ΣVi × γc）+ 台腔回填（V填 × γs，可选）+ 土压力竖向分量 EaV
2. **水平力** ΣH = 制动力 Hk + 土压力水平分量 EaH
3. **抗滑移** Kc = μ·ΣV / ΣH ≥ 1.3
4. **抗倾覆** 只验算绕基底**前趾**（河心侧）取矩，即向河心倾覆。**ΣM稳 的每一项**都按「竖向力 × 作用点至前趾的顺桥向距离」计算，逐项为：
   - 台身（前墙）自重 = V前墙 × γc
   - 侧墙（两道）自重 = V侧墙 × γc
   - 帽梁自重 = V帽梁 × γc
   - 背墙自重 = V背墙 × γc
   - 牛腿自重 = V牛腿 × γc（h腿/h腋 为 0 时不列）
   - 基础自重 = V基础 × γc（一、二层合计）
   - 台腔回填土重 = V填 × γs（勾选时计入）
   - 支座竖向反力 = Nk，力臂 = 支座作用点 x（前趾 x = 0，故坐标值即力臂）
   - 土压力竖向分量 = EaV，力臂 = 其作用点 x = 基础前伸 + t1 + (H1−yc)/m1（合力点高于前墙顶时取基础前伸 + t1）

   **ΣM倾** 只由水平力构成，力臂都是竖向高度：`ΣM倾 = Hk·hH + EaH·yEa`
   - `hH = H1 + 帽梁高 + dH + 基础总厚`：制动力作用点至基底的竖向距离（H1 为前墙高，dH 为作用点距帽梁顶的高度）
   - `yEa = 基础总厚 + h填/3`：三角形分布合力点至基底

   默认参数下：hH = 5.00 + 0.60 + 0.10 + 1.00 = **6.700 m**，yEa = 1.00 + 6.50/3 = **3.167 m**，故 ΣM倾 = 165.0×6.700 + 653.8×3.167 = 1105.5 + 2070.3 = **3175.8 kN·m**；ΣM稳 = 50678.4 kN·m（含 EaV 的稳定力矩 1631.3），K0 = 50678.4 / 3175.8 = **15.96 ≥ 1.5**。

   K0 = ΣM稳 / ΣM倾 ≥ 1.5。台后土压力恒指向河心且远大于制动力，水平力合力不可能指向台后，后趾工况不控制，故不再验算后趾。结果表中已逐项列出各力的体积、容重、力臂与力矩，可直接手算复核。

   > **支座反力 Nk 是抗倾覆力，不是倾覆力。** 它是竖向力，力臂为顺桥向水平距离，故计入 ΣM稳（Nk 增大则 K0 单调上升）；倾覆力矩只能由水平力产生，因为只有水平力才具备竖向力臂。Nk 若作用点偏河心，会把基底合力往河心拉、加大偏心与 p最大，那属于基底承载力范畴，与抗倾覆是两个不同的验算。
5. **基底承载力**（直线分布假定）：**原点已设在基底前趾底边中点（基础河心侧最外边缘、基础底面的中点，即抗倾覆的倾覆点），x 坐标值即「距前趾的距离」、z 坐标值即「距基底的高度」，全表无负坐标**。基底长 `L = 基础前伸 + 桥台长 L2 + 基础后伸`，形心在基底中点、距前趾 `L/2`；基底弯矩 **M竖 = ΣV·L/2 − ΣVi·ai**（`ai` 为各竖向力至前趾的力臂，`ΣVi·ai` 即 ΣM稳）+ **M水 = ΣM倾**，两者都使前趾受压、方向相同，必须同向叠加而不能相减；p均 = N/A；p最大/最小 = N/A ± 6M/(B·L²)；要求 p均 ≤ fa、p最大 ≤ 1.2fa、偏心距 e = |M|/N ≤ L/6（岩石 L/4）。e > 0 表示合力偏河心（前趾受压），e < 0 表示偏台后。
   表中每行都给出**代入数值的算式**（可直接逐位复算），默认工况为：
   - 基底面积 `A = B×L = 14.00×8.00 = 112.00 m²`，`N = ΣV = 13703.501 kN`
   - `L = 1.000 + 6.000 + 1.000 = 8.000 m`，形心距前趾 `L/2 = 8.00/2 = 4.00 m`，竖向合力点距前趾 `ΣVi·ai/ΣV = 50678.4/13703.5 = 3.698 m`
   - `M竖 = ΣV·L/2 − ΣVi·ai = 13703.5×4.00 − 50678.4 = 54814.0 − 50678.4 = 4135.636 kN·m`，`M水 = ΣM倾 = 3175.817 kN·m`，`M = 4135.6 + 3175.8 = 7311.453 kN·m`
   - `e = |M|/N = 7311.5/13703.5 = 0.534 m ≤ L/6 = 8.00/6 = 1.333 m`
   - `p均 = N/A = 13703.5/112.00 = 122.353 kPa ≤ fa = 400`
   - `6|M|/(B·L²) = 6×7311.453/(14.00×8.00²) = 43868.7/896.00 = 48.9615 kPa`
   - `p最大 = 122.3527 + 48.9615 = 171.313 kPa ≤ 1.2fa = 480`；`p最小 = 122.3527 − 48.9615 = 73.392 kPa ≥ 0`

   算式中的加减项取 4 位小数（`p均`、`6|M|/(B·L²)`），以保证「两项相加减」与右侧结果列在三、四位小数上严格吻合。
   > **两个容易混淆的「合力作用点」**：①**竖向合力作用点**距前趾 `= ΣVi·ai / ΣV`（`ai` 为各竖向力至前趾的力臂，ΣVi·ai 就是 ΣM稳），只反映竖向力的偏心，默认 **3.698 m**（距后趾 4.302）；②**基底反力合力作用点**距前趾 `= L/2 − e`，是把水平力倾覆 ΣM倾 也折算进去之后基底反力三角形的合力位置，默认 `4.000 − 0.534 = 3.466 m`，p最大/p最小 由它决定。两者相差 `M水/ΣV = 3175.8/13703.5 = 0.232`。
   > **为什么形心是 4.000**：坐标原点已从「前墙前缘」移到**基底前趾底边中点**（基础河心侧最外边缘、基础底面的中点，即倾覆点），故 `前趾 x = 0.000`、`后趾 x = 基础前伸 1.000 + L2 6.000 + 基础后伸 1.000 = 8.000`，形心在基底中点 `L/2 = 8.00/2 = 4.00`。这个 4.00 既是距前趾的距离，也是形心的 x 坐标——新原点下两者合一，不再出现「坐标 3.000 / 距离 4.000」并存的情况。若基础前后外伸不等，形心坐标仍为 `L/2`（距前趾），只是不再等于 `L2/2 + 后伸`。

各构件自重按**几何形心**取矩：前墙梯形用解析形心 (b₁²+b₁b₂+b₂²)/(3(b₁+b₂))，侧墙与回填按断面面积加权数值积分（Simpson, 200 段），牛腿按直角梯形断面形心，帽梁/背墙/基础按矩形。形心已用三维网格四面体分解独立校核（误差 < 0.02 m）。

## 稳定与承载力验算（桥墩）

左侧「验算参数（标准值）」卡 + 右侧同名结果表，随几何与参数实时刷新，分五节：

| 节 | 内容 | 算式 |
|---|---|---|
| 一、竖向力 | 盖梁自重 Gc、墩身自重 Gp、基础自重 Gf、上部结构反力 Nk、ΣV | G = 体积 × γc（体积取工程量表口径） |
| 二、水平力 | 制动力 Hk、ΣH | 顺桥向，指向河心为不利方向 |
| 三、抗滑移 | Kc | Kc = μ·ΣV / ΣH ≥ 1.3 |
| 四、抗倾覆 | 力臂 hH、ΣM倾、ΣM稳、K0 | hH = 模型顶（墩顶 + 盖梁高）+ dH + 基础总厚；ΣM倾 = Hk·hH；ΣM稳 = ΣV·a/2（绕基底前趾）；K0 = ΣM稳 / ΣM倾 ≥ 1.5 |
| 五、基底承载力 | A、M、e、e 限值、p均、p最大、p最小 | A = a×b；M = ΣH·hH；e = \|M\|/N ≤ a/6（岩石 a/4）；p均 = N/A；p最大/最小 = N/A ± 6\|M\|/(b·a²)，要求 p最大 ≤ 1.2fa、p最小 ≥ 0 |

约定：`a` = 基底纵桥向长、`b` = 基底横桥向长（设二层基础时取二层底面）；竖向力过基底中心（Nk 按作用于墩中心），故不产生偏心力矩，弯矩仅由水平力产生；本表未计横桥向水平力、基础顶面覆土重与浮力，横向可按同一方法补充。

## 公式排版与导出 Word

验算表的计算式不再用裸文本写 `yEa1` 这类名字，而是**一条 TeX 源**交给 MathJax 排版：参数名有真正的上下标（`E_{aH}`、`y_{Ea}`、`K_{a}`、`p_{均}`），分式、根号、度数按数学体排。

- **只写一份源，三处复用**：
  1. 页面显示 —— `MathJax.tex2svg()` 转 SVG 插回表格；
  2. 导出 Word —— `MathJax.tex2mml()` 得 MathML，再用微软 `MML2OMML.XSL` 转 **OMML**，写进 docx 的 `word/document.xml`。Word 里是**原生公式对象，双击即可编辑**（不是图片，也不是纯文本）；
  3. 无 MathJax 环境（无头校验、纯文本场合）—— 表格里保留 `texPlain()` 生成的**可读降级文本**（如 `EaH＝Ea·cos(θ+δ)`），不会露出反斜杠控制符。
- **点验算表标题最右侧的「导出.docx验算书」** 得到 A4 横向 docx（文件名 `项目名-验算书.docx`），按顺序包含：
  1. **表1 计算参数表** —— 直接扫描左侧参数卡的当前值（含自动计算项与开关状态），按卡片分组输出「参数 / 取值 / 说明」三列，**参数在最前面，便于先核对输入**；
  2. 表2（桥墩页还有工程量计算表）**稳定与承载力验算表** —— 分节标题 + 项目 / 计算式 / 数值 / 单位 / 判定五列。计算式列里中文是普通文字、公式是 OMML，可逐个双击修改后继续排版；
  3. **六张计算示意图** —— 网页里 SVG 画的图，导出时按**原表格行位置**经 canvas 转 PNG（2 倍分辨率）嵌入（宽度按版面限幅 ≤610px），图下附原图注。docx 由页面自带的**极简 STORE 模式 ZIP 打包器**现场生成（约 60 行，含 CRC32），不依赖 JSZip / pako，单文件离线可用。
- **公式的可读性**：`.mj` 的字号取 `calc(1em + 1px)`（比所在单元格的字大 1px），颜色固定为正文色 `--ink` —— MathJax 的 SVG 根节点带 `fill="currentColor"`，若不显式指定会继承 `td.fx` 的次级灰而显得发虚；同时计算式列的灰字由 `#64748b` 加深到 `#334155`，与公式的对比度接近。
- 六张计算示意图在网页里是内联 SVG；导出 Word 时经 canvas 转 PNG 后嵌入对应行，不再是「Word 版不嵌图」。

| 内嵌素材 | 大小 | 作用 |
|---|---|---|
| `mathjax_tex_svg.js` | 2.1 MB | MathJax 3（TeX 输入 + SVG 输出），构建时替换 `/*__MATHJAX__*/` |
| `mml2omml.xsl` | 152 KB | Office 的 MathML→OMML 样式表，构建时剥注释、去 XML 声明后替换 `/*__MML2OMML__*/` |

代价是桥台页从 0.76 MB 涨到 3.0 MB；换来的是公式排版与可编辑 Word 导出都不需要联网。

> 二次开发提示：`harness.js` 里「文本是否存在」这类断言读的是降级文本（先 `plainify()` 去标签、还原 `.mj` 内容再匹配），改公式文案时只要保证 `texPlain()` 的产物仍含关键字即可；`rowOf()` 的窗口按 4000 字符取，因为 `.mj` 带 `data-tex` 属性，单行 HTML 比纯文本长得多。

## 约定

- 单位：m、m³；长度显示 2～3 位小数。
- 桥台坐标系：**原点 = 基底前趾底边中点**（基础河心侧最外边缘、基础底面的中点，即抗倾覆的倾覆点）；x = 纵桥向（指向台后，前趾 x = 0、前墙前缘 x = 基础前伸、帽梁前缘 x = 基础前伸 − ec、后趾 x = 基底长 L）、y = 横桥向（宽度中点 y = 0）、z = 竖向（**自基础底面起算，倾覆点 z = 0**，因此表中竖向力臂 yEa、hH 的数值就是 z 坐标）。标高以**基础底面 = 0.000** 计（相对标高 0.000 ≡ 坐标原点 z = 0，前墙底标高 = 基础总厚，二者数值一致无需换算）。
- **符号口径**：顺桥向坐标一律记作 **x**（如"作用点 x = 2.074、基底前趾 x = 0.000"），竖向坐标记作 **z** 或直接写"标高"；抗倾覆、基底承载力结果表中的坐标与三维坐标轴标签同名同向同原点（原点 = 基底前趾底边中点，x 指向台后，z 自基础底面向上）。该基准下 **x 坐标的数值就等于距基底前趾的距离、z 坐标的数值就等于距基底的高度**，全表不再出现负坐标，力臂即作用点坐标。
- 桥墩坐标系：**原点 = 基础最低面（最下层基础底面）中心**；x = 纵桥向、y = 横桥向（左右对称、宽度中点 y = 0）、z = 竖向（向上为正，基础底面 z = 0，墩底 z = 基础总厚）；标高以**基础底面 = 0.000** 计（墩底标高即等于基础总厚；盖梁位于墩顶以上）。页面内部建模仍以「墩底 = 0、基础在 z<0」书写，展示坐标 = 场景 z − (−基础总厚)，三维坐标轴（`AxesHelper` 与箭头组）同步下移到 `z = −基础总厚`，原点十字与坐标轴标签也在同一位置。
- 绝对标高 = 相对标高 + 高程基准绝对标高；**基准点 = 基础底面（即坐标原点 z = 0）**，故相对标高的数值就等于坐标 z（距基底的高度），`z = 相对标高`，前墙底/墩底标高 = 基础总厚。
- 坡比一律写作「竖:横」，1:1 即 45°。
